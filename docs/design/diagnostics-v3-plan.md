# 诊断页 v3 迭代计划

> 配套示例：[diagnostics-v3.html](./diagnostics-v3.html)（当前为设计评审稿，未接线）

## 1. 目标与约束

- 视觉风格沿用 v2，信息元素不删减；
- 按分类组织内容，用底部导航栏切换分类；
- 底部导航栏适配 Android 手势沉浸（`env(safe-area-inset-bottom)`，后续接线时宿主走 edge-to-edge）；
- 流程：示例 HTML 评审迭代 → 定稿 → 接线 `MasterSwitchActivity` → 真机验证。

**V3-15 实施方案（接线阶段实施）**

- 目标：状态行（`status.*`）任何时候都反映最近一次触发；事件环（`events` / `events.jsonl`，即反馈包时间线）仍仅录制期间采集，反馈包语义不变。
- 机制：复用 native 补丁状态豁免的同一套实现（`MLog.isStatusEssentialEventName` + `DiagnosticEventReceiver` 状态必需名单），把状态归类所需事件全部加入名单；非录制期间只做状态归类，不进事件环。
- 覆盖范围（按优先级）：
  1. 低频启动/注入/结果类：`scope.*`（含 V3-07）、`hook.host`、`inject.*`、`bridge.*`、`native.patch.*`、`dexkit.*`、`remember.*`、`replay.*`、`game.mode.*`、`codec.write` 等——直接豁免；
