## 简体中文

### 2.5.3：AAC/SBC 耳机与游戏低延迟兼容
- 为没有官方「游戏模式」入口的耳机补充独立「游戏低延迟」总开关，放在模块音质区；游戏自动切换 LE Audio 仍按耳机能力显示。
- 总开关关闭时，兼容路径阻止系统下发的经典 SBC 低延迟入场请求，帮助 AAC/SBC 耳机在进入游戏时保持已选择的 AAC；普通 SBC、AAC 和退出低延迟请求正常放行。
- 修正 SBC 退出标记被误当成低延迟活动的问题，避免 AAC 记忆回放在退出后继续受到抑制。
- 修复扩展工厂被频繁读取时反复安装 Hook、打印相同缺类堆栈的问题；合并安装期间的新信号，并保留扩展晚加载后的安装机会。私有低延迟类不可加载时明确记录兼容路径。
- PJZ110 / Android 16 的本次用户日志确认了独立入口注入、SBC 入场请求拦截及随后 AAC 音频流启动。

### 包含 2.5.2：X4 类耳机共存状态修复
- 区分 LE Audio 使用许可、连接状态与实际媒体路由，修复 X4 类「LE Audio + 经典蓝牙共存」设备在使用经典协议时被误显示为 LC3 或一直连接中的问题。
- 根据耳机的官方 BR/LE 地址映射读取媒体输出；经典蓝牙播放时保留协议、音质与采样率控制，无法确认路由时显示等待确认。
- 游戏内切换及退出恢复后刷新媒体路由、经典协议快照和相关诊断状态，减少过期状态残留。

### 升级与边界
- 安装后重新加载官方「无线耳机」及蓝牙作用域，再确认模块开关状态。
- 旧系统的兼容路径负责阻止后续 SBC 低延迟入场。若关闭开关前已经处于低延迟 SBC，请先退出游戏或重连耳机并恢复 AAC。
- 不同系统与耳机组合仍需各自验证；本次日志验证不代表所有机型及长期听感均已验收。

## English

### 2.5.3: AAC/SBC headsets and game low-latency compatibility
- Adds an independent Game Low Latency master switch in the module's audio-quality section when the headset has no official Game Mode entry. Automatic game switching to LE Audio remains capability-gated.
- When the master switch is off, the compatibility path rejects classic SBC low-latency entry requests, helping AAC/SBC headsets retain the selected AAC codec when entering a game. Normal SBC and AAC choices, and low-latency exit requests, remain available.
- Corrects the handling of the SBC exit marker so that leaving low latency no longer keeps AAC memory replay suppressed.
- Prevents repeated Hook installation and duplicate missing-class stack traces on frequent extension-factory reads. Installation signals are coalesced without losing late extension readiness; unavailable private low-latency classes are reported as a compatibility path.
- The supplied PJZ110 / Android 16 capture confirms independent control injection, rejection of an SBC entry request, and subsequent AAC audio-stream startup.

### Includes 2.5.2: X4-class coexistence state fixes
- Separates permission to use LE Audio, profile connectivity, and the actual media transport. X4-class headsets supporting LE Audio and classic Bluetooth coexistence no longer appear as LC3 or remain stuck connecting while media uses a classic codec.
- Resolves media output against the headset's official BR/LE address mapping. Classic playback retains codec, quality, and sample-rate controls; unconfirmed routes are shown as awaiting confirmation.
- Refreshes media routes, classic-codec snapshots, and diagnostics after in-game switching and restoration, reducing stale state.

### Upgrade notes and limits
- Reload the official Wireless Headphones app and Bluetooth scopes after installation, then confirm the module's switch settings.
- On older systems, the compatibility path prevents subsequent SBC low-latency entry. If SBC low latency is already active when disabling the switch, leave the game or reconnect the headset and restore AAC first.
- Other system/headset combinations need their own validation. This capture does not establish universal device coverage or long-term listening acceptance.
